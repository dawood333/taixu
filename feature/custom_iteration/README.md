# Custom Iteration Feature

The Custom Iteration feature lets the Agent assist with modifying the TaiXu application itself. It provides an entry point for describing a change, preparing the relevant project context, and progressing through an implementation workflow.

Treat generated changes as code, not as trusted output. Review diffs before applying them, keep changes within the intended workspace, run the relevant tests, and build the application before considering a modification complete. Never include API keys, access tokens, or private configuration in prompts or generated artifacts.
