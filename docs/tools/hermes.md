# Hermes Tool

Hermes is installed and managed through the TaiXu tool center. The adapter handles installation, verification, updates, and uninstall. Since upstream scripts and CLI behavior may change, pin versions and review the official installation source before release.

Keep persistent configuration and user data in the tool data directory, separate from executable files. Never commit API keys or tokens. Test install, launch, health check, update, and uninstall on an ARM64 Linux runtime before release.
